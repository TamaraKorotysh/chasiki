# Часики

Веб-игра для детей: совёнок Тик учит понимать часы со стрелками.

- 8 уроков: круг с цифрами → часовая стрелка → минутная → половина → четверти → минуты по 5 → секундная стрелка → любые минуты и запись 3:13
- Игры «Найди» и «Поставь», «Мой день», «Мастерская часов», «Живые часы»
- Всё озвучено (голос браузера), прогресс сохраняется в браузере

Запуск: открыть `index.html` в браузере.
